# Symbaroum — Tradução PT-BR

Módulo de localização para **Symbaroum no Foundry VTT**, aplicado por meio do **Babele**. Ele traduz o sistema e os compêndios oficiais compatíveis sem modificar os módulos originais.

Os textos de jogo seguem as edições brasileiras publicadas pela **Tria Editora**. Guias e mensagens técnicas sem edição oficial foram localizados usando a terminologia oficial do jogo.

## Requisitos

- Foundry Virtual Tabletop v13;
- sistema Symbaroum;
- módulo Babele;
- módulo oficial Symbaroum Core Rules;
- módulos oficiais correspondentes aos conteúdos adicionais que você deseja usar.

## Instalação

No Foundry VTT, abra **Módulos Add-on → Instalar módulo**, cole a URL abaixo em **URL do Manifesto** e instale:

```text
https://raw.githubusercontent.com/Kciquehn/symbaroum-ptBR/main/module.json
```

Ative o módulo no mundo e mantenha o idioma do Foundry configurado como **Português (Brasil)**. Conteúdos importados antes da ativação ou de uma atualização podem precisar ser importados novamente.

## Conteúdo compatível

- Core Rules;
- Advanced Player's Guide;
- Monster Codex;
- Adventure Collection, exceto as aventuras A5 e A6, que não possuem edição oficial em PT-BR;
- Game Master's Guide;
- guia de uso e macros do sistema Symbaroum.

Este módulo não inclui os livros, PDFs ou os bancos de dados dos produtos oficiais. É necessário possuir e instalar cada módulo comercial correspondente.
