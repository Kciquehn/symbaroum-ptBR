# Compêndios legados

Os bancos LevelDB desta pasta são artefatos antigos de desenvolvimento e não são declarados no `module.json`.

Eles não devem ser expostos como compêndios do módulo sem uma migração controlada: há versões duplicadas do guia, dados de teste e textos com codificação antiga. O guia atualmente utilizado pelo módulo é `templates/user-guide-ptBR.html`, acessível pelo link da mensagem inicial.
